# Interior Archive Print

A reusable image-generation Skill for transforming a single interior, architecture, furniture, or lived-space photograph into a **3:4 vertical editorial composition** combining faithful photography with a retro archival print reconstruction.

## Concept

**REAL / MEMORY / PHOTOGRAPH**  
×  
**ARCHIVE / INTERPRETATION / PRINT**

The upper half preserves the uploaded photograph. The lower half reconstructs the same space using restrained linocut, woodcut, screen-print and Risograph-inspired visual language.

## Core characteristics

- strict vertical 3:4 output;
- approximately 1:1 upper/lower division;
- strong source-image fidelity;
- no arbitrary furniture or architecture redesign;
- warm off-white uncoated paper;
- deep brown-black ink structure;
- one scene-derived spot/accent color;
- linocut / woodcut hatching;
- screen-print / Risograph texture;
- generous negative space;
- tiny typewriter / monospaced archival typography;
- adaptive multilingual microcopy;
- no invented locations, dates, architects, or product facts.

## Workflow

`Analyze → Lock Composition → Extract Palette → Reconstruct → Print Treatment → Typography → Final QC`

See `SKILL.md` for the complete execution rules.

## Typical use

Upload one image and ask to generate it using **Interior Archive Print**. Optional context such as location, date, brand, preferred language, or accent color can be supplied, but is not required.

If metadata is unknown, the Skill uses neutral observational copy instead of fabricating factual information.
